# Multi-Asset VaR & Stress Testing

This project builds a Python-based portfolio risk analytics framework for a multi-asset portfolio. It covers return calculation, volatility analysis, downside risk, Value-at-Risk, stress testing, and scenario analysis using financial time-series data.

## Project Objectives

- Construct a multi-asset portfolio using public financial data
- Calculate portfolio returns and volatility
- Estimate downside risk and Value-at-Risk
- Run stress-testing and market decline scenarios
- Produce clear risk commentary for portfolio decision-making

## Methods

- Data cleaning and return calculation
- Portfolio weighting and benchmark comparison
- Historical volatility
- Downside risk analysis
- Historical Value-at-Risk
- Stress testing under adverse market scenarios

## Tools

- Python
- pandas
- NumPy
- matplotlib
- yfinance or other public financial data sources

## Disclaimer

This project is for educational and portfolio demonstration purposes only. It does not use confidential, proprietary, Bloomberg, Refinitiv, or employer-owned data.
